Chapter I

Apparatus

Three instruments. One open laboratory.

The WombDAO extension is an in-browser lab bench. It pulls live data from NCBI, runs a literature-trained agent over it, and settles research decisions against an on-chain treasury.

Instrument 001

Primary source data

No synthetic examples. WombDAO reads directly from NCBI's Gene Expression Omnibus — the same RNA-seq and single-cell datasets cited in peer-reviewed embryology journals.

Instrument 002

A reading-room agent

Free models via OpenRouter, grounded in the indexed GEO archive. Ask about gene expression, compare embryonic stages, cite the source in one click. Local-first, no telemetry.

Chapter III

Protocol

Five steps from install to proposal.

A short protocol, kept honest. No seed phrases in the extension, no servers in the middle, no shadow mempool. Read what you run.

Install the Chrome extension

Load WombDAO from the Chrome Web Store. Thirty seconds, zero accounts. The extension runs entirely client-side.

Connect a Base wallet

MetaMask, Rabby, Coinbase Wallet, or any WalletConnect-v2 provider. The extension never sees your seed.

Search the GEO archive

Query by gene, by developmental stage, by author. Results stream from the indexed vector store with citations attached.

Reason with the agent

Ask follow-ups grounded in the data. Export the conversation to Markdown with inline GEO accessions for your lab notebook.

Vote with $WOMB on Base

Every active proposal is one click away. Votes settle on Base in ~2 seconds, gas under a cent.
