Tool-call integration (Claude / GPT / Gemini)

Expose WombDAO as two tools — search and ask — for any function-calling LLM.

// Tool definition (JSON schema, Claude-compatible) { "name": "wombdao_search", "description": "Search WombDAO's ectogenesis dataset archive", "input_schema": { "type": "object", "properties": { "q": { "type": "string" } }, "required": ["q"] } } // Tool handler async function wombdao_search({ q }) { const r = await fetch(`https://womborg.up.railway.app/api/search?q=${encodeURIComponent(q)}`); return (await r.json()).results; }

Agent Mode (structured JSON)

Pass agent_mode: true to /api/chat for a response shaped for downstream parsing.

curl -X POST https://womborg.up.railway.app/api/chat \ -H "Content-Type: application/json" \ -d '{ "messages": [{"role":"user","content":"NANOG by stage"}], "agent_mode": true }' # Response { "success": true, "reply": "NANOG peaks at morula stage [GSE36552]...", "citations": [{"id":"GSE36552","url":"...","score":0.84}], "sources": [{"id":"GSE36552","title":"...","samples":124}], "model": "meta-llama/llama-3.1-8b-instruct:free" }

MCP server wrapper

A minimal MCP server exposing WombDAO as tools:

import { Server } from "@modelcontextprotocol/sdk/server"; const BASE = "https://womborg.up.railway.app"; const server = new Server({ name: "wombdao", version: "0.2.0" }); server.setRequestHandler("tools/call", async ({ name, arguments: args }) => { if (name === "search") { const r = await fetch(`${BASE}/api/search?q=${encodeURIComponent(args.q)}`); return { content: [{ type: "text", text: await r.text() }] }; } if (name === "chat") { const r = await fetch(`${BASE}/api/chat`, { method: "POST", headers: { "Content-Type": "application/json" }, body: JSON.stringify({ messages: args.messages, agent_mode: true }) }); return { content: [{ type: "text", text: await r.text() }] }; } });

Playwright / Browserbase

If your agent drives a real browser, the Web Agent at /agent is fully automatable — stable selectors, no auth, no captcha.

await page.goto("https://womborg.up.railway.app/agent"); await page.fill("#chatInput", "What datasets cover methylation?"); await page.click("#sendBtn"); await page.waitForSelector(".msg.agent .citations"); const reply = await page.textContent(".msg.agent:last-child .text");

Crawling & discovery

  • /robots.txt — permissive, API paths allowed
  • /sitemap.xml — all pages + top dataset URLs
  • JSON-LD Organization, WebSite, Dataset on every page
  • Semantic HTML5 throughout (<article>, <section>, proper headings)

Rate limits & etiquette

300 requests per 15 minutes per IP. If you need more, open an issue on GitHub. Chat endpoints cost compute — cache responses when practical and pass a stable User-Agent identifying your agent.
